# PST-VTU29652 — Problem Solving and Testing in Java

All hands-on tasks listed in the two supplied weekly lesson-plan documents are organized by week and session. Each task has its own folder, a descriptively named `.java` file, and a task README.

## Requirements
- JDK 17 or newer recommended
- Visual Studio Code
- Extension Pack for Java

## Run a task
Open the task folder and use the run button, or follow the `javac` / `java` commands in that task's README. Each source file includes a sample in `main()` for local testing. Online judges may require their exact input/output format.

## Weeks
- [Week 1](Week_1/README.md) — Functional programming and lambda expressions
- [Week 2](Week_2/README.md) — map, filter, reduce, streams and collections
- [Week 3](Week_3/README.md) — Date/time handling, collections and custom comparators
- [Week 4](Week_4/README.md) — Constraint-driven design, competitive patterns and matrices
- [Week 5](Week_5/README.md) — Maximum subarray, Kadane's algorithm and strings
- [Week 6](Week_6/README.md) — Pattern matching, KMP applications and palindrome techniques
